# 使用说明

> 目标：读完这一页，你能把它用起来；剩下的细节按 `?`（键位总表）和设置里的「说明」页随用随查。

## 一、安装

| | |
| --- | --- |
| **安装版** | 双击 `WakeyWeeky_<版本>_x64_en-US.msi`（需要管理员权限）。升级直接装新版即可，**不会动你的数据**。 |
| **便携版** | 解压 `WakeyWeeky-<版本>-portable.zip`，双击里面的 `WakeyWeeky.exe`。数据写在同目录 `data\` 里。 |
| **系统** | Windows 10 / 11（64 位）。Windows 11 自带 WebView2；Windows 10 若提示缺 WebView2，装一次 [运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。 |

第一次运行 Windows 可能提示「未知发布者」（安装包没做代码签名）：点「**更多信息**」→「**仍要运行**」。

## 二、界面一眼看懂

```text
┌────────────────────────────────────────────────────────────────┐
│  ‹ 本周 ›   ▦ 总览  ▤ 统计  ▥ 模板  ⚙ 设置                      │  ← 顶栏
├──────────────┬─────────────────────────────────────────────────┤
│  任务池       │   周一   周二   周三   周四 …                    │
│  （Backlog）  │  ┌────┐                                          │
│  添加任务…    │  │ 块 │   ← 把任务从左边拖到这一格               │
│  ▸ 任务 A     │  └────┘                                          │
│  ▸ 任务 B     │  08:00 09:00 10:00 …                            │
└──────────────┴─────────────────────────────────────────────────┘
        底部：本周每天的「精力」占用条（对着每日预算比）
```

- **左**：任务池。加任务、改名字、设预估时长 / 分类 / 每周重复都在这里。
- **右**：本周 7 天 × 48 格。块就是「这件事被安排在什么时刻」。
- **顶**：切周、总览、统计、模板、设置。
- **底**：本周每天的占用条 —— 哪天排太满了会变红提醒你。

## 三、五个基本动作

1. **加任务**：左边「添加任务…」打字 → 回车。
2. **排进去**：把任务拖到右边某一格。拖块的**边缘**可以改时长。
3. **到点处理**：提醒弹出时点「完成」或「未完成」——这一步是它跟普通清单的区别。
4. **临时的事**：双击时间轴空白格，直接放一个「临时安排」（不用先建任务）。
5. **回头看**：`▦ 总览` 看这周结果；`▤ 统计` 看趋势；`▥ 模板` 把某周存成骨架。

## 四、时间轴上的手势

| 想做什么 | 怎么做 |
| --- | --- |
| 搬一块 | 按住块拖到别处，松手放下（`Ctrl+Z` 撤销） |
| 改时长 | 拖块的**上/下边缘** |
| 复制 | 选中后 `Ctrl+C` —— 预览跟着鼠标走，**左键落地**；`Ctrl+X` 是搬移版 |
| 选多块 | `Ctrl+左键` 加选 / `Shift+左键` 选一段 / 空白处拖出框选；`Ctrl+A` 全选这一周 |
| 整组搬 / 复制 | 多选后 `Ctrl+X` / `Ctrl+C`，左键落地 |
| 标记完成 / 未完成 | 选中块按 `Space`（完成）/ `X`（未完成） |
| 不计入精力 | 块或任务的 `⊘`（临时例外 / 长期例外） |
| 删除 | 选中按 `Del` |
| 放弃手上的操作 | `Esc` |

**融合**：同一任务相邻的两块会自动接成一块（省得手动对齐）。
**残影**：块被挪走或删掉后，原位置会留一道浅色记号，方便你回忆刚才动过什么。
**跨周**：拖到时间轴边缘停一下会翻周；跨过周日的块会在相邻两周里各显示一段。

## 五、提醒

- **开始时提醒**：到块的开始时刻说一句（可以设「提前 5 / 10 / 15 / 30 分钟」）。
- **结束时提醒**：问「完成还是未完成？」——这条通知上直接带按钮，点一下就算答了。
- **免打扰**：工具栏的静音按钮可以「暂停 30 分钟 / 2 小时 / 到明早（时刻可改）」。静音期间的提醒**不发、只静默记账**，解除后不会补发一串。
- **复盘提醒**：默认**什么都不做**（可以改成「只提醒我」或「直接打开总览」）—— 不想被催就保持默认。
- **关掉应用也要按时提醒**（默认**关**）：打开后会在 Windows 任务计划程序里注册一条任务，应用没运行也能唤醒提醒。**只有你亲手打开才会注册**，关掉即注销。

## 六、序列与漂流

- **序列**（⛓）：把「有先后顺序」的几块串起来。前一块被挪动时，后面的会跟着走 / 自动顺延；被打断会给你提示。
- **漂流卡**：没排上的任务会主动来问「还要不要安排」——「自己安排」把块挂到鼠标上，或者「稍后」「不再提」。

## 七、复盘与统计

- `▦ 总览`：这周的**完成 / 未完成 / 未执行 / 计划中**、每天的明细、**类别投入对比**（本周 vs 基线）、**两周马赛克对比**（按状态或按类别）。
- `▤ 统计`：连续几周的趋势、类别分布。
- **精力条**：底部每天的小条 = 那天所有块占用的时间（**重叠的只算一次**，`⊘` 的不算），对着可调的**每日预算**（默认 6 小时）比 —— 超了变红。

## 八、模板与每周重复

- **模板** = 某一周的骨架（层 / 时段 / 时长 + 任务名与分类）。`▥ 模板` 里可以「保存这一周为模板」，也可以把模板铺到正在看的那一周（同名任务复用，不重复建）。
- **每周重复**：在任务池某条任务的 `⚙` 里加规则（周几 + 时刻 + 层）。以后打开任一周，它已经排好了（块上有 `🔁` 记号）。
  - 时长照任务的**预估**（没填 = 30 分钟）；想改某一次，直接拉伸那一块。
  - 删掉生成的那一块 = **这周不再生成**，规则还在。

## 九、外观与设置

设置分几组，常用的在这里：

| 组 | 有什么 |
| --- | --- |
| 外观 | 配色（12 套，其中 9 套带装饰与展示字）、深浅色（跟随系统 / 亮 / 暗）、密度、字号、**界面字体族**（默认 / 宋 / 楷 / 等线 / 等宽）、图标集、时间刻度、现在线、块内第二行显示什么 |
| 布局 | 任务池形态（展开 / 细轨）、隐藏周末、键位提示栏 |
| 时间与日期 | 12 / 24 小时制、日期格式（默认跟随系统） |
| 夜间 | 夜间淡化 + 时段（默认 22:00 – 06:00） |
| 提醒 | 开始 / 结束开关与提前量、复盘动作与时刻、免打扰时刻 |
| 功能开关 | 二期新增的功能面都可以单独关（**关掉只收界面与行为，不删数据**） |
| 键位 | 重绑快捷键（见下一节） |
| 数据 | 备份 / 恢复 / 导出 `.ics` / 便携 / 数据位置 |
| 更多 | 说明页、重看新手卡片、重置统计、恢复默认设置 |

## 十、快捷键

按 `?` 打开**键位总表**（随时可查）；键位可以在设置里改。

| 键 | 作用 |
| --- | --- |
| `←` `→` | 上一周 / 下一周 |
| `T` | 回到本周 |
| `C` | 快速加任务（展开任务池并聚焦输入框） |
| `?` | 键位总表 · `Ctrl+,` 打开设置 |
| `O` | 打开总览 · `S` 打开统计 |
| `Ctrl+A` | 全选这一周 |
| `F2` | 改任务名 |
| `Ctrl+X` / `Ctrl+C` | 搬移 / 复制（预览跟鼠标，左键落地） |
| `Space` 完成 · `X` 未完成 · `Del` 删除 | 对选中的块 |
| `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`） | 撤销 / 重做 |
| `Enter`（选中块） | 拿起 → 方向键预览移动 → `Enter` 落地（`Esc` 放弃） |
| `WASD` | 在块之间移动选中 |
| `Ctrl+滚轮` | 调时间轴的刻度（每格高度） |
| `Win+Shift+W`（全局） | 在别的程序里也能唤起主窗口（占用时依次退到 `Ctrl+Alt+W` / `Ctrl+Alt+Shift+W`） |

## 十一、你的数据

```text
%APPDATA%\com.wakeyweeky.app\wakeyweeky.sqlite      ← 默认位置
<应用目录>\data\wakeyweeky.sqlite                   ← 便携模式
```

- **导出备份**：存成一个一致副本（任务 / 块 / 序列 / 模板 / 设置都在里面）。
- **从备份恢复**：覆盖当前数据并自动重启；**重启前会自动留一份「恢复前副本」**，不对还能换回来。
- **导出日历 `.ics`**：导进手机 / 系统日历（时间是 UTC，导入后显示的是**同一时刻**；重复导入同一文件不会重复生成）。
- **便携模式**：打开后数据跟着应用文件夹走，整个文件夹拷到 U 盘就能带走。切换时会把两份数据**并排摆出来**（位置 / 最后修改 / 大小 / 任务·块数），你选哪份用哪份 —— 被覆盖的那一侧会先留副本（**只复制、从不删**）。便携模式下「提醒计划」不可用。
- **卸载**不会删除数据。

## 十二、常见问题

**它联网吗？** 不联网。没有任何网络请求、没有遥测、没有更新检查（可用防火墙观察验证）。

**会偷偷在后台跑吗？** 不会 —— 计划任务默认关，只有你显式打开才注册。

**数据会丢吗？** 数据是一个标准 SQLite 文件，任何 SQLite 工具都能打开；启动时会做完整性检查。建议偶尔导出备份到别的盘。

**能同步到手机吗？** 没有云同步（刻意的）。可以导出 `.ics` 看日程，或导出备份自己搬。

**界面有英文吗？** 有，设置里切换（默认跟随系统）。

**能改成别的配色 / 字体吗？** 能：12 套配色 + 深浅色 + 密度 + 字号 + 五档界面字体族，都在设置 → 外观里。

**为什么我的块变红 / 顶部有提示？** 那天的占用超过了每日预算（精力）；改预算或把块 `⊘` 掉即可。
